# M11A Genericity Audit

## Result

The M11A recall, policy-area authority, mechanical same-parent episode accounting, eligibility, and ranking lane is domain-neutral for the fixed representative. The bounded deeper-source resolver contains National Security indicators because M11A has one provisionally selected domain; it does not affect another domain's authority or ranking. No accepted Justice semantics, Semantic IR, UI behavior, database state, schema, CORS, or deployment file was changed.

## Current-lane checks

- Domain selection accepts the six canonical non-excluded domain IDs and applies one accounting and ranking function to all of them.
- The fixed member, Congress, checkpoint, and cutoff are milestone scope, not issue-specific semantic constants.
- Candidate recall uses the shared member-neutral classifier vocabulary. Recall cannot establish membership, and title words cannot override a non-target Congress.gov policy area.
- Canonically mapped Congress.gov policy areas directly establish ordinary whole-measure membership. Cross-domain whole measures require deeper action-specific official evidence. Amendment evidence remains exact and roll-bound; parent-measure evidence cannot establish a child action.
- Procedural, expressive/nonbinding, exact-action-ineligible, cross-domain, and unresolved rows remain distinct and non-counting.
- Counted episode candidates use only exact same-parent legislative identity. The executable National Security War Powers geography collapse was removed from selection, ranking, and accounting.
- Two possible cross-measure War Powers relationships remain visible as `future_episode_review_candidates`; they have no authority effect and contribute to no M11A count. This selected-domain review note is not a reusable episode model.
- The review and source artifacts bind canonical action identity, member action, House action stage, evidence role, source identity, URL, and digest.

## Findings outside the current lane

- Historical M3-M10 Justice authoring and packaging scripts intentionally contain F000477, Justice, 37-action, and 32-episode constants. They reproduce frozen accepted records and are not invoked by M11A.
- The original Justice source-readiness schemas are case-specific acceptance contracts. Reusing or generalizing them in place would risk changing accepted Justice behavior, so they remain unchanged.
- The legacy publication-activation module and development artifact bundle retain Justice-specific fixtures and identities. M11A neither invokes nor modifies them.
- The live editorial selector has a canonical issue allowlist that already includes National Security & Foreign Policy; no new public presentation is created in this milestone.
- Future action interpretation cannot safely start by invoking the Justice-specific M3-M10 builders. The next milestone must either parameterize a new candidate-authoring lane behind the accepted contracts or create a separate domain-neutral implementation. That is a follow-up gate, not a blocker to universe discovery.
- A later cross-domain scaling milestone must define equivalent action-specific boundary resolvers for other selected domains. M11A acquires and evaluates deeper summaries only for its bounded National Security cross-domain cases.

## Protected regression boundary

Any proposed change that alters accepted Justice action membership, interpretations, episode identities, proposition meaning, synthesis, presentation wording, publication selection, or Selected Issue Experience behavior is a stop condition. M11A changes none of those paths and validates the existing Justice Semantic IR independently.

# Foushee Justice Action Interpretation Decisions V1

## Intent

Prepare a detached, non-authorizing human decision surface for all 37 immutable
V4 candidates after the external `generalization_pass` decision.

## Scope

- Bind every decision unit to M1, M2, and final-byte-verified V4 identities.
- Derive deterministic review tiers without party, motive, synthesis, or public
  presentation inputs.
- Surface review-relevant compressed details separately from candidate meaning.
- Keep Codex recommendations structurally separate from empty human decisions.
- Generate Markdown from canonical JSON and validate final-byte parity.

## Non-scope

No candidate acceptance, candidate mutation, canonical interpretation, episode,
proposition, Semantic IR, synthesis, persistence, publication, deployment, or
remote repository activity.

## Definition of done

Exactly 37 decision units exist; all human fields are empty; special ambiguous
and no-safe cases remain bounded; JSON, Markdown, schemas, and final hashes agree;
the V1–V4 roots remain unchanged; and one local unpushed snapshot is committed.

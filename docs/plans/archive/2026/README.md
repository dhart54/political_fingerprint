# 2026 Plan Archive

Plans in this directory are immutable historical execution records. They describe completed milestones and do not override current user instructions, `AGENTS.md`, the active plan, repository workflows, methodology, or interpretation principles.

Archival does not mean deletion, product approval, publication approval, or current applicability. Git history remains the authoritative change history. Archived plans may still be cited as historical evidence.

The directory-level notice is intentional: archived plan contents are preserved without substantive rewriting or banners that could obscure their original milestone record.

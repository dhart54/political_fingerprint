# Foushee Justice Policy-Episode Decision Implementation V1

## Intent

Implement the 32 delegated-accepted M4A policy-episode candidates exactly in a
detached internal bundle and stop for delegated implementation acceptance.

## Scope

M4B imports the immutable delegated M4A acceptance, copies every accepted
episode field without semantic revision, implements the complete 37-action
episode accounting, carries the cumulative risk register and calibration
population into detached successors, and generates closed schemas, an internal
dossier, an independent parity report, an empty decision template, and
final-byte parity. It does not create canonical episodes, Semantic IR,
propositions, synthesis, public language, persistence, publication, or
deployment authority.

## Sequence

1. Verify offline safety, repository identity, preserved snapshots, the exact
   acceptance record, and M1 through M4A governed inputs.
2. Transform each accepted frozen candidate into one
   `implemented_delegated_episode_candidate` record with exact field and digest
   bindings.
3. Reproduce exactly one accounting record for each of the 37 actions.
4. Preserve all eight risks, extend only the accepted FISA disposition history,
   and bind the 30 calibration-eligible episodes to implementation digests.
5. Generate the dossier, independent parity report, empty delegated decision
   template, closed schemas, and final-byte parity manifest.
6. Run adversarial and regression validation, inspect the complete diff, create
   one local unpushed snapshot commit, and stop.

## Definition of done

Exactly 32 episode records implement the frozen batch with no field drift; the
episode accounting remains 30 single-action and 2 multi-action episodes; action
accounting remains 35 assigned, 1 retained ambiguous, and 1 no-safe unassigned;
rolls 155 and 278 remain non-counting; the risk and calibration successors are
continuous; and no implementation becomes canonical, public, persisted,
published, authorizing, or accepted before the delegated implementation gate.

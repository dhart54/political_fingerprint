# Foushee Justice Policy-Episode Candidates V1

## Intent

Construct neutral, detached policy-episode candidates for all 37 accepted M3B-B
action-accounting records and stop for delegated-authority review.

## Scope

The milestone imports the delegated M3B-B acceptance, builds action lineage,
initial and corrected candidate episodes, separated review artifacts, a frozen
batch, post-freeze benchmark comparison and deterministic samples, cumulative
launch-risk and calibration populations, an empty decision template, schemas,
Markdown, and parity. It does not accept episodes or authorize propositions,
Semantic IR, synthesis, persistence, publication, delivery, or deployment.

## Sequence

1. Verify offline safety, immutable snapshots, acceptance, and M1–M3B-B inputs.
2. Build neutral lineage and an initial complete accounting without benchmark
   access.
3. Run overgrouping, undergrouping, chronology/role, behavior, ambiguity/no-safe,
   and double-counting reviews independently.
4. Apply one evidence-bound global correction cycle and freeze the batch.
5. Compare benchmark structure and select review/challenge samples only after
   freeze.
6. Generate risk, calibration, dossier, decision, schema, and parity artifacts.
7. Validate, inspect the full diff, and create one local unpushed snapshot.

## Definition of done

Every approved action has exactly one primary accounting state; roll 155 remains
ambiguously unassigned, roll 278 remains no-safe and unassigned, all other
actions appear once across candidate episodes, final major/critical review
findings are zero, and no candidate enters canonical or public state.

# Foushee Justice Action Interpretation Decision Implementation V1

## Milestone intent

Implement the 37 delegated editorial decisions exactly into detached, non-public
records and stop for delegated-authority acceptance. The immutable external
authority JSON is controlling; its companion Markdown is a readable projection.

## Scope and non-scope

This milestone creates closed implementation, governance-mapping, launch-risk,
calibration-eligibility, dossier, schema, and parity artifacts. It does not
establish canonical semantics, select a calibration sample, construct episodes
or Semantic IR, persist or publish data, access a database or network, or deliver
the branch remotely.

## Implementation sequence

1. Verify the repository snapshots and exact authority bytes and digests.
2. Recompute each implementation record from immutable V4, M3B-A, and authority
   inputs.
3. Generate the successor mapping, cumulative risk register, deferred calibration
   population, Markdown projection, schemas, and parity manifest.
4. Independently verify all 37 decisions and run adversarial drift tests.
5. Inspect the complete diff and create one local, unpushed snapshot commit.

## Definition of done

The result contains exactly 32 unchanged acceptances, two exact authorized
revisions, two preserved ambiguities, and one preserved no-safe record. All
artifacts remain detached and pending delegated-authority acceptance and launch
ratification; final paths and hashes agree; the worktree is clean after the local
commit.

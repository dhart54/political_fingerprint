public/persistence guards active. The opt-in behavioral candidate compiler's
accepted-episode requirement is not a prohibition on documentary preparation.
Its upstream full-universe authority receipt requires
`full_defined_issue_record` / `approved_complete_issue_universe`; those constants
do not describe this bounded pilot. No complete executable acceptance chain is
claimed. Missing required bindings remain explicit rather than fabricated.

blob bytes were restored after verifying the fixed SHA-256; no semantic or Git
content changed. Source identities use pinned Git bytes and canonical JSON to
avoid treating checkout newline conversion as evidence drift. The original ZIP
remains unverified.

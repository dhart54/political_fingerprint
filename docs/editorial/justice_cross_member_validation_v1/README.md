# Justice Cross-Member Validation V1

This review-only bundle reuses the five Justice & Public Safety episodes researched in PR #95 for Valerie P. Foushee and six additional House members. It does not alter or duplicate the shared dossiers.

The evidence path is: shared episode contract → declarative episode-action interpretation → member episode themes → generic aggregation and candidate evaluation → member-specific synthesis. `episode_action_interpretations.json` and `candidate_catalog.json` make the Justice semantics reviewable; `member_overlays.json`, `inference_candidates.json`, and `comparison_matrix.json` contain the derived member results.

`cohort_selection.json` documents all 437 members appearing in at least one substantive roll, their seven recorded actions, completeness, and selection status. `official_action_sources.json` records the official House Clerk sources and descriptive party-majority context. `shared_episode_reuse_contract.md` defines fail-closed coverage and the shared/member boundary.

Every artifact is `human_approval_pending`, `not_promoted`, and production-ineligible. This is a small-cohort framework validation, not a ranking or nationwide validation.
